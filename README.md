# Build Engine app (scaffold)

This project was scaffolded by the Build Engine. The Executor will fill in features.

## Stack

- Next.js 16 + TypeScript (strict)
- Vitest for unit tests
- ESLint via `next lint`

The full v1 stack (Drizzle, Better Auth, Tailwind) is layered in by the Executor as plan tasks rather than baked into this minimal scaffold.

## Run locally

1. **Set up your database.** Copy the example env file and fill in your Postgres connection string:

   ```bash
   cp .env.example .env.local
   # Edit .env.local and set DATABASE_URL=postgres://user:pass@host:5432/dbname
   ```

2. **Install dependencies and start the dev server:**

   ```bash
   pnpm install
   pnpm dev          # http://localhost:3000
   ```

3. **Other commands:**

   ```bash
   pnpm test:run     # vitest (all tests)
   pnpm lint         # ESLint
   pnpm exec tsc --noEmit  # type-check
   ```

> **Note:** `DATABASE_URL` must be set before running `pnpm dev`. The app reads it at startup via `lib/db/client.ts` and will throw a clear error if it is missing.
